# 单文件 HTML 演示

使用 `$wepr-slides` 处理 Bento 格式；其他 HTML 演示也必须保持资源、导航和讲稿可交付。

适用能力包括浏览器全屏和多方式导航、Morph、状态页、动态数字、交互图表、媒体、当前页与下一页预览、计时、讲稿、观众屏同步及现场控制。

每页使用稳定 ID，避免重排后讲稿、计时和页面状态串位。提供低性能或断网降级方案；动态背景和动画不能影响正文可读性。交付前至少用目标浏览器检查 16:9、全屏、窗口缩放和演讲者模式。

编辑或分发前检查文档中的协作字段，避免把所有者、写入者或邀请凭据随文件或 JSON 一起交付。若凭据已经外发，仅从当前文件删除并不能撤销旧副本的访问权，应提示用户停止共享或轮换密钥。

交付时明确文件名和保存位置，提醒用户重新打开保存文件，而不是把始终生成新文档的网页入口当作原文件。主题可切换时同时检查明暗模式对比；媒体分别验证自动播放开启和关闭；任何解析、保存、导出或渲染警告都必须呈现并复核，不能把被吞掉的错误当作成功。
