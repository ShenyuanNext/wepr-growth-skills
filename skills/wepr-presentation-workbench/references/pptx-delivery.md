# 原生 PPTX 交付

## 路线

- **新建：** 从主题或资料建立叙事、页面计划和全新演示。
- **模板填充：** 使用客户提供的 `.pptx`，先识别母版、版式、占位符和可替换范围，再填充内容。
- **视觉重构：** 保留事实和叙事，重做层级、布局、图表、图像和主题。
- **局部增强：** 只修改指定页面、备注、动画、图表或视觉元素。
- **图片还原：** 以截图作为视觉参考时，重新构建可编辑对象；无法可靠还原的部分明确说明。

文本使用文本框，数据使用可编辑图表或表格，流程使用形状和连接线，公式使用支持的公式对象。只有照片、插画和无法合理重建的复杂视觉才使用位图。

模板填充前检查页面尺寸、母版、版式、占位符、主题字体、主题颜色、页码、页脚和隐藏页面。不要用新建白板覆盖客户模板的母版逻辑。

编辑现有文件时保存原件，输出新文件。逐页渲染后再判断视觉是否正确；文件成功生成不等于交付合格。

文字宽度检查要区分中文、全角、半角和拉丁字符，不能对所有字符套用同一加粗或宽度系数；机器估算只用于发现风险，最终以实际渲染为准。SVG 检查应兼容 XML 声明、注释和文档类型声明，不能只根据扩展名或文件是否直接以 `<svg` 开头判断。脚本捕获异常后必须返回明确失败或警告，不得用空结果伪装成功。
