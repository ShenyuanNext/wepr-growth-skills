# 限色视觉系统

## 1. 选择色版

先根据传播任务选择颜色性格，再检查品牌资产、载体和无障碍对比度。不要把固定色值当成普遍答案。

- 单色：适合观点海报、研究封面、低成本印刷和需要高度统一的系列。
- 双色：适合需要区分主体与行动、信息与情绪、现实与假设的画面。
- 主墨应覆盖主要轮廓、标题关系和视觉重量；强调墨的面积通常明显小于主墨，并集中在少数关键位置。
- 纸张可以是暖白、冷白或有轻微纤维感的中性色，但不得成为第三块高饱和色。
- 输出前分别检查彩色显示、灰度缩略图和小尺寸预览；若焦点只靠色相差异维持，应增加明度、形状或位置差异。

## 2. 组织构图

优先从以下结构中选择一种，不同时堆叠：

- 单体主导：一个人物、产品或符号占据主要视觉面积。
- 文字碰撞：短标题与主体形成遮挡、穿插或尺度对比。
- 剪纸窗口：利用纸张负形揭示第二层含义。
- 单一手势：一笔涂抹、框选、撕裂或盖印承担强调功能。
- 双区对照：左右、上下或前后两种状态形成清晰判断。

主事件之外保留安静区域，让标题、说明或平台界面有可用空间。背景纹理不能平均铺满到失去层级。

## 3. 选择复制机制

每张图选择一项主要机制：

- 半调网点：适合照片、人物和明暗建模；网点尺度应与最终尺寸匹配。
- 孔版颗粒：适合手工、文化和社区感；允许轻微墨量不均，但主体边缘仍应可读。
- 复印断裂：适合议题、档案和实验性内容；控制黑位堵塞与细节丢失。
- 蓝晒质感：适合研究、自然、工程和档案主题；避免把所有中间调压成同一块蓝。
- 套色偏移：适合强调运动、冲突和人工印制；偏移应有方向和目的，不能造成品牌文字不可读。

## 4. 建立系列一致性

系列作品至少固定四项：画布比例、纸张、主墨、复制机制、标题位置、边距、纹理强度或主体裁切方式。每张图只改变主题需要改变的内容，避免“每张都好看但放在一起不像同一项目”。
