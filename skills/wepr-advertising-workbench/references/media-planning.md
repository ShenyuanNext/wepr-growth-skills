# 媒体方案与预算

## 最小输入

明确业务结果、转化定义、产品价格、毛利或贡献利润、LTV、销售周期、退款或取消窗口、现金与信用上限、月度和平台预算、创意产能、地域、行业限制和历史数据。

## 平台角色

不要默认覆盖所有平台。按用户意图、受众可达性、内容形态、测量能力、销售周期、经济性、团队能力、政策风险和资产复利价值比较。早期项目通常只需要一个主平台、一个辅助平台和一个有限实验。

## 方案结构

1. 业务问题和媒体任务。
2. 目标受众、触发情境与转化路径。
3. 平台角色、选择依据和明确排除项。
4. 账户、广告系列、受众和创意结构。
5. 预算、节奏、现金边界与学习安排。
6. 追踪、归因、CRM 回传和数据责任。
7. 创意系统、落地页和销售承接。
8. 实验路线、30/60/90 天动作、负责人和依赖。
9. KPI、基线、目标逻辑、停止与扩量规则。
10. 合规、隐私、平台和交付风险。

## 核心经济指标

使用统一口径计算：

- `CPA = 广告花费 / 被接受的转化数`
- `ROAS = 被接受的转化价值 / 广告花费`
- `CAC = 获客相关总成本 / 新客户数`
- `MER = 业务总收入 / 总营销支出`
- `贡献利润 = 收入 - 变动成本 - 履约成本 - 广告成本`

计划缺少经负责人确认的经济上限时只能是临时方案，不能据此自动扩量或改账户。

## 预算分配

从业务限制和边际证据出发，不使用固定平台占比。为每个平台写明基础预算、实验预算、保留预算、最大损失、决策日期、增减条件和重新分配逻辑。把品牌、需求捕获、再营销、零售媒体和实验预算的任务分开。
