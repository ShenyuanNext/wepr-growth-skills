# 数据分析方法

## 先选择最小资料范围

普通研究学习使用离线阅读器，含两类研究报告与论文索引，不含论文 PDF、原始 JSONL、Parquet 和 DuckDB。阅读器的 WEPR 导航页链接 WEPR 官网；研究页面和必需权利文件保留原样。

仅在需要复算时取所需数据目录，并检查目录说明、数据清单和质量报告。固定源版本，核验分片 SHA-256，再准备 Python 3.11+ 与 uv。不要直接执行远程脚本，也不要在含未保存改动的数据工作区运行强制重建。

## CN-GEO 的分析层

- 原始记录：回答一个问题时出现的一条外部引用，不等于完整回答。
- 规范问题：记录规范化方法和对应原始表达。
- 信源：区分平台内路径、域名与组织主体，避免未经确认的归并。
- 规范页面：保留原始 URL、规范 URL 和去重依据。
- 引用观察：保留平台代码和终端；区分原始计数与去重计数。
- 页面特征：说明缺页、抓取失败和特征提取时间。
- 分析集市：先核对主键和指标定义，再作跨平台比较。

目录示例使用只读 DuckDB 查询 `source_visibility` 的 `deduplicated_citation_count` 和 `platform_code`。实际分析前检查表结构；不假定所有快照都具有相同字段。表不存在或指标不可计算时报告缺口，不生成替代数据。

## 不足字段如何影响结论

缺采集时间 → 不做趋势；缺完整回答 → 不做可靠情感或推荐率；缺回答批次 → 不把引用行数当回答分母；缺模型版本 → 不将差异归因为某次模型更新；缺转化数据 → 不从引用推算收入。公开历史样本可以帮助设计实验，不能充当客户当前品牌基线。

## 复算与交付

输出数据版本、来源清单、校验结果、清洗决策、缺失概况、查询或脚本、统计表与可重现步骤。生成的客户报告使用 WEPR 标识和服务描述，引用研究时保留准确作者及出处。发布任何原始数据或论文 PDF 前逐项确认其允许的再分发范围；本技能默认不复制这些大文件。
