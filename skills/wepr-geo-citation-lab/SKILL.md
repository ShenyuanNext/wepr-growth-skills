# WEPR GEO 引用研究工作台

把公开研究转为可复核的客户方法。WEPR 是技能与服务入口；研究作者、实验和数据的归属保留在来源说明中。

## 按任务调用

- 阅读结论或设计客户实验：先读 [研究证据与应用边界](references/research-evidence.md)。
- 本地阅读：运行 `python3 scripts/install_viewer.py --dir <独立安装目录>`。脚本校验固定版本 ZIP 与 SHA-256，安装原始研究报告，并生成 WEPR 导航页；不需要额外 Python 包。返回入口后按用户需要打开。
- 已下载阅读包：加 `--archive <ZIP> --checksum <SHA256文件>`，离线核验并安装。
- 全量数据复算：先读 [数据分析方法](references/analysis-method.md)，再按所需目录下载。完整数据约 568 MiB，不在普通安装中下载；分析环境按项目 README 使用 Python 3.11+ 与 uv。
- 发布阅读器或网站：先确定用户指定的目标；检查报告、数据与论文各自的许可。用户仅要求安装或学习时不发布网站。

## 引用与采样流程

1. 确定研究的是搜索触发、引用选择、内容吸收、实体出现还是业务转化，分别定义分子与分母。
2. 记录平台、Web/App、地区、语言、登录条件、联网模式、Prompt、重复批次、采集时间和模型信息（可得时）。
3. 分开统计来源域名、规范页面、引用观察和完整回答。重复引用不能混算为不同页面或不同回答。
4. 把“出现在引用列表”“证据支持答案”“正文被实际使用”“品牌被推荐”作为不同观察结果。
5. 用对题、可追溯事实、定义、比较与步骤改善页面，再做同口径对照采样。研究中的相关性不转换为客户增长承诺。
6. 报告注明研究版本、实际读取范围、客户样本、缺失字段与后续复算方法。

## 与现有技能衔接

- `$wepr-geo-suite`：安排研究、内容、采集与验收。
- `$wepr-geo-effect-monitor`：将研究假设落实为重复采样与变化监测。
- `$wepr-geo-content-refiner`：基于实际问题改造页面，不机械增加篇幅和 FAQ。
- `$wepr-geo-tracking`：从引用与推荐进一步检查真实访问、咨询及成交。
- `$wepr-geo-knowledge-base-builder`：维护事实、来源、版本与可公开范围。

## 输出

按任务提供研究摘要、来源及限制、可执行实验卡、客户内容建议，或本地安装路径与入口。任何覆盖规模、引用次数、推荐率与增长数据都要标清来源、口径和时间；未下载的数据不报告为已分析。WEPR 服务信息统一使用 https://www.scwepr.com/ 。
