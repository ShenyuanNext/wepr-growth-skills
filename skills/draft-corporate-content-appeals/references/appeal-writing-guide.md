# 申诉写作与证据指南

仅在需要起草具体申诉、成功率矩阵或盖章文件时读取本指南。

## 一、内容分类与主要抓手

| 类型 | 识别方式 | 主要抓手 | 常见企业材料 |
|---|---|---|---|
| 精确事实 | 日期、金额、比例、人员、设备、合同或具体行为 | 指向可核验记录，证明错误、矛盾或主体不匹配 | 台账、制度、合同、工资考勤、邮件、访客与招聘记录 |
| 排他性/唯一性宣传 | “行业唯一”“市面上唯一”“只有本品牌能做到” | 用真实、同期、可对应型号的一个反例直接击穿排他性结论 | 官网参数页、说明书、检测报告、购买记录、上市时间证据 |
| 竞品拉踩 | 点名竞品无功能、廉价贴牌、不专业、专利来自代工厂 | 将功能事实与贬损评价拆开；先反证参数，再要求发布者证明贴牌、专利归属及利益关系 | 产品说明书、专利证书、研发/生产资料、品牌及授权文件 |
| 转述传闻 | “听说”“前同事说”“据说” | 非亲历、来源不明、无法核验，叠加严重贬损 | 人员名册、查询说明、业务或人事记录 |
| 混合表达 | 用少量事实导出整体负面结论 | 拆开事实与评价，重点攻击虚假事实前提 | 与事实前提直接对应的反证 |
| 纯主观评价 | “混乱”“水平差”“没格局” | 删除率通常较低；寻找侮辱、骚扰、虚假身份或组合传播 | 上下文截图、账号关联、传播记录 |
| 劳动违法指控 | 无年假、不缴公积金、违法辞退、不赔偿、违规竞业 | 每项对应具体法定记录，避免空泛否认 | 规章制度、社保公积金凭证、解除与补偿记录、裁判查询 |
| 招聘/面试叙事 | 面试轮次、岗位、薪资、背调、面试官 | 核验主体、日期、岗位、人员和原始沟通；抓时间线矛盾 | ATS 记录、邮件、访客登记、授权书、聊天记录 |
| 监控或隐私指控 | 摄像头、录音、持续监控、泄露个人信息 | 场所、设备、用途、告知与授权均可核验 | 点位图、采购台账、制度、告知书、信息处理记录 |
| 版权 | 原作品被复制、搬运或未经许可传播 | 权属、原创时间、实质性相似与未经授权 | 源文件、首次发表、登记证书、授权链 |
| 商标/冒充 | 假账号、仿冒页面、虚假授权或混淆性标识 | 来源混淆、账号真实性、商业使用与损害 | 商标证、官网账号清单、授权证明、混淆截图 |

## 二、逐条申诉模板

### 被投诉内容

“逐字引用，不改写，不把多名用户内容合并为一人。”

### 申诉理由

该内容对我司【具体事项】作出可核验的事实陈述，并据此形成【具体负面结论】。发布者未提供【逐项列明应有凭证】，亦未说明【身份、任职期间、岗位、地点、样本、统计口径或信息来源】。现有页面内容无法确认【事件发生、主体对应、数据来源或结论成立】。

经我司对【核验部门、期间和记录范围】核查，【仅填写企业有材料支持的结论】。我司可提供【盖章说明及附件名称】作为初步证明，请平台结合发布者提交的原始凭证进行核验。

【说明时间矛盾、逻辑跳跃、传闻性质、以偏概全或侮辱性】。该内容公开传播后，容易使【求职者、从业人员、客户、合作伙伴或社会公众】误认为我司【具体错误印象】，降低我司社会评价，并对【招聘、交易、客户关系或正常经营】造成持续影响。

上述内容缺乏有效证据及可核验的事实基础，呈现明显的非善意贬损和恶意引导特征。请平台核实后立即删除该内容；如暂不能删除，请先停止推荐、降低传播、取消搜索展示并保存相关发布及处置记录。谢谢。

## 三、竞品对比与唯一性宣传的专项写法

这类投诉不要只写“夸大宣传、恶意拉踩”，而应建立两层论证。

第一层是可直接反证的事实：

1. 完整引用“行业唯一”“其他品牌均无某功能”等排他性表述；
2. 明确该表述可以通过产品型号、参数、上市时间和功能说明客观核验；
3. 提供至少一个真实竞品反例，并写清品牌、型号、功能名称、参数范围及操作方式；
4. 用官方详情页、说明书、检测报告、专利或购买/上市记录证明反例在涉诉内容发布时已经存在；
5. 得出限定结论：“该反例足以证明其‘唯一’及‘竞品均无’的绝对化表述与客观事实不符。”

第二层是无证据的贬损和商业导向：

1. 将“专业品牌”与“廉价贴牌”“室内玩具”“专利属于代工厂”等表述分别列出；
2. 指出发布者未提供研发主体、生产关系、采购合同、专利权属、授权链、质量检测或价格品质比较依据；
3. 说明其一面绝对化拔高被推广品牌，一面点名否定竞品，足以误导消费者对产品功能、研发能力和品牌信誉的判断；
4. 如页面存在购买链接、优惠码、品牌合作标识或连续推广记录，可据此说明商业推广及利益关联；证据不足时只称“具有明显推广导向”，并请求平台核查。

推荐结构：

> 该内容在集中宣传【被推广品牌】的同时，点名比较【竞品】，包含可客观核验的排他性功能陈述以及对竞品研发、生产或品质的贬损。首先，发布者称【唯一性原文】。但【竞品型号】已具备【具体功能及参数】，附件【编号】所示的【官方参数页/说明书等】足以直接否定“唯一”及“竞品均无”的绝对化结论。其次，发布者又称【贴牌、廉价、不专业等原文】，但未提供【研发、生产、专利权属、检测等证据】，属于以无依据的贬损性标签抬高被推广品牌、降低竞品社会评价。该内容具有明显的竞品导向和商业推广色彩，可能误导消费者并影响公平竞争。请平台核验其商业合作、广告标识及证据来源，删除不实比较和贬损内容，并停止推荐、搜索展示和传播。

不要仅凭单一页面截图认定“故意造谣”“受品牌委托”或“恶性竞争”。只有在能够证明利益关联、广告投放、重复模板、指令关系或明知反例仍发布时，才升级使用上述表述。

## 四、强势措辞的证据门槛

| 拟用表述 | 使用条件 | 证据不足时改写 |
|---|---|---|
| “虚假内容” | 企业记录能直接否定核心事实，且核验范围完整 | “缺乏可核验事实基础，与我司现有记录不符” |
| “恶意诋毁” | 有重复发布、勒索、明确敌意、虚假身份或组织传播证据 | “呈现非善意贬损和恶意引导特征” |
| “网络水军” | 有账号关联、任务群、交易、批量模板或平台核查结果 | “请平台核查账号关联关系及异常发布行为” |
| “从未发生” | 可检索范围覆盖全部相关主体、地点与期间 | “在已核查的【范围】内未发现相应记录” |
| “严重违法” | 法律适用明确且事实材料充分 | “涉嫌违反【具体规则】，请平台核验” |

不要保留“删除该该内容”“发布者未我司无任何关系”等病句。平台申诉应使用准确、克制、可校验的法律中文。

## 五、证据配置

每条投诉至少准备：

1. 企业营业执照或登记证明；
2. 经办人身份证明、授权委托书及联系方式；
3. 完整页面截图、URL、账号、发布时间和取证时间；
4. 逐项核验说明，写明部门、范围、期间和查询结果；
5. 能直接反驳核心事实的附件；
6. 盖章的真实性承诺；
7. 已造成影响时，补充求职者询问、客户反馈、招聘取消、传播量或搜索结果等材料。

对劳动、人事、薪酬、背调等敏感材料，优先提交脱敏版本；若平台需要原件核验，可说明愿意通过受控渠道补充。

## 六、成功率评估

成功率是基于内容类型、证据强度和平台规则的工作估计，不是历史统计或结果承诺。默认用区间：

- 较高，约 70%–85%：主体明确、核心内容为可证伪事实、企业反证直接完整，并有明显矛盾或冒充情形。
- 中等，约 45%–70%：事实与评价混合，企业有部分反证，但仍需平台向发布者核验原始资料。
- 较低，约 20%–45%：主要为传闻或强烈贬损，缺少企业直接反证；可争取限流、停止推荐或要求补证。
- 很低，约 5%–25%：主要为一般性主观评价、真实经历或合理批评，且无侮辱、隐私、冒充或知识产权问题。

逐条评估至少写明：支持成功的因素、降低成功率的因素、最有效的补强材料、首选路径和备选路径。遇到平台、司法辖区或证据差异较大时，调整区间并解释原因。

## 七、盖章《情况说明及真实性承诺》结构

1. 标题及对应内容编号；
2. 企业全称、统一社会信用代码、注册地址；
3. 被投诉平台、URL、账号、原文；
4. 核查部门、核查期间、核查系统或资料范围；
5. 逐项事实结论，避免超出核查范围；
6. 对企业声誉及经营影响；
7. 明确请求删除、停止推荐与搜索展示；
8. 真实性承诺及愿意承担虚假投诉责任；
9. 附件目录；
10. 法定代表人或授权代表签字、公章及日期。

每条内容原则上单独成件，避免不同账号、不同事实或不同链接互相污染。正文中保留可替换的核验范围和附件编号，供企业实际审核后填写。

## 八、境外平台的路径限制

- X、YouTube 等平台优先查其现行社区规则、冒充规则、隐私规则、版权表单和商标表单。
- 香港或其他法域的诽谤路径应结合发布地、阅读地、主体及损害联系判断；不要简单套用中国内地法律。
- DMCA 通知必须针对受版权保护作品的未经授权复制，并满足法定声明和签名要求。批评企业、引用公司名称或发表负面观点本身不构成 DMCA 理由。
- 商标申诉重点是商业来源或授权混淆；描述性提及、新闻评论和批评性使用通常不能仅凭商标权删除。
- 若最强路径是诽谤而平台没有事实核验入口，可保全证据、发律师函或按适用法寻求披露/禁令，但应提示成本、管辖和反诉风险。
