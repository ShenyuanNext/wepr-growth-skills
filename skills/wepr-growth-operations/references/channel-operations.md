# 渠道运营模块

## 内容与社交平台

按问题触发 → 搜索/浏览意图 → 证据 → 内容格式 → 行动入口 → 评论/私信/落地页承接 → 销售或服务组织。关注有效搜索覆盖、合格互动、有效线索和成交辅助。不得伪造素人、评论或口碑。

## 付费媒体

顺序为贡献毛利与可承受 CAC → 转化事件与追踪 → 平台角色 → 人群与意图 → 创意/报价 → 落地页 → 销售跟进 → 对账。预算、出价和平台比例依据当前数据；平台产品、政策和算法查官方最新资料。

## 私域、社群、电商与本地

区分受众名单、兴趣社区、客户服务群和转化群，明确成员价值、门槛、沉淀、职责、转化边界、生命周期和退出机制。电商同时管理商品、流量、转化、客服、履约、退款、评价、库存和复购。本地业务先筛选点位、客群、决策人、客单、毛利、容量和履约条件，贯通触达至成交、上线、服务、回访、对账和复购。

## AI 与渠道选择

只自动化人工已跑通、重复且规则明确的环节；配置授权、人工审批、速率、日志、抽检和回滚。禁止批量灌水、账号矩阵滥用、绕过审核或虚假互动。

按客户密度、意图、信任适配、素材能力、承接、追踪、经济性、团队、风险和学习速度选渠道。每个渠道定义一个主要角色：发现、教育、证明、收口、留存或转介绍。
