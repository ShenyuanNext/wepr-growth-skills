# 运营系统、SOP 与组织节奏

先画出客户任务、产品/报价、流量入口、承接、销售、成交、交付、留存/复购、转介绍与数据回流。每轮只指定一个主要瓶颈。

每条工作流写明目标、触发、输入、步骤、负责人、协作者、工具、输出、质量门槛、时限、证据、异常分支、升级路径和复盘指标。SOP 还应包含适用范围、前置条件、判断点、质检、审批、记录字段、版本和更新时间。只固化已验证动作。

## 节奏与责任

- 每日：异常、线索质量、交付阻塞、预算与风险。
- 每周：漏斗、内容/创意、销售反馈、实验决策和资源调整。
- 每月：单位经济、渠道组合、客户洞察、容量、复购和优先级。
- 每季度：定位、产品组合、组织能力、技术债和停止事项。

用 RACI 标明最终负责、执行、协作和知会。会议必须产生决策、负责人和截止时间。

## 客户方案结构

执行摘要 → 现状证据与瓶颈 → 运营主张与最小闭环 → 工作流与渠道分工 → 阶段路线图 → 内容/流量/转化/交付/留存机制 → KPI 与复盘 → 团队/RACI/治理 → 预算/单位经济/风险 → 待确认决策。页面标题表达判断或动作，不使用空泛栏目名。
