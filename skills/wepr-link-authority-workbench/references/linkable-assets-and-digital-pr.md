# 可链接资产与数字公关

## 资产选择

| 用户需要 | 可用资产 | 必备证据 |
| --- | --- | --- |
| 理解决策 | 方法指南、选型框架、计算器 | 方法、适用边界、更新日期 |
| 获取数据 | 行业研究、趋势数据、基准 | 样本、口径、时间、限制 |
| 验证能力 | 案例、实验、技术说明 | 原始记录、条件、反例 |
| 快速执行 | 模板、清单、开放工具 | 使用说明、维护责任 |
| 判断变化 | 专家解读、事件说明 | 专家资历、原始来源、时效 |

每项资产写明目标受众、核心问题、独特性、事实负责人、目标 URL、更新频率、可能引用者、分发角度和业务转化路径。

好传播角度应同时满足：当前相关、对受众有后果、客户有可核验贡献、能用一句话说明、不过度承诺。新闻稿并不自动产生媒体价值；缺少新事实时，优先制作资料、解释、案例或合作内容。

媒体包可包含事实卡、方法说明、数据表、可授权图片、专家简介、引语草案、常见问答、利益关系和联系人别名。所有引语需由具名发言人批准。
